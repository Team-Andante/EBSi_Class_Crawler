# 📚 EBSi Class Crawler

[![License: MIT](https://img.shields.io/badge/license-MIT-blue.svg)](./LICENSE)
![Python](https://img.shields.io/badge/python-3.8%2B-blue.svg)

**[EBSi](https://www.ebsi.co.kr)** 사이트의 학년별·과목별 강좌 목록을 자동으로 수집해 CSV로 저장하는 파이썬 크롤러입니다. `Selenium`으로 동적 렌더링 페이지를 불러오고 `BeautifulSoup`으로 강좌명, 강사명, 강좌구분, 난이도, 링크를 파싱합니다.

> **Ver 1.0** - 최초 배포  
> **Ver 2.0** — 크롤링할 학년을 코드 수정 없이 터미널 입력만으로 선택할 수 있습니다.

## 주요 기능

- 🎓 실행 시 터미널 입력만으로 크롤링 대상 학년(고1 / 고2 / 고3) 선택
- 🔁 학년별로 미리 정의된 과목 · 카테고리 코드 · 페이지 수 기준으로 전 과목 자동 순회
- 🌐 Selenium + `webdriver-manager`로 ChromeDriver를 자동 설치하고 headless 모드로 크롤링
- ⏳ 강좌 카드가 로드될 때까지 명시적으로 대기(`WebDriverWait`)한 뒤 파싱해 데이터 누락 최소화
- 🧾 강좌별 **과목 / 강좌명 / 강사 / 강좌구분 / 난이도 / 링크** 추출
- 💾 결과를 UTF-8(BOM 포함) CSV로 저장해 엑셀에서 열어도 한글이 깨지지 않음

## 동작 원리

1. **`init_set()`** — 터미널로 학년(1~3)을 입력받아 `GRADE`와, 크롤링할 과목 정보(`SUBJECTS`: 과목명 → `[카테고리 코드, 페이지 수]`)를 설정합니다.
2. **`init_driver()`** — headless 옵션을 적용한 Chrome WebDriver를 생성합니다.
3. **`crawl_subject()`** — 과목별 `categoryCode` · `cookieGradeVal` 쿼리 파라미터로 목록 URL을 구성하고, 지정된 페이지 수만큼 `pageIndex`를 바꿔가며 순차적으로 접속합니다. 매 페이지마다 강좌 카드(`.cont_wrap`)가 나타날 때까지 최대 10초 대기합니다.
4. **`parse_page()`** — 로드된 HTML에서 강좌 카드 단위로 강좌명 · 링크(`.tit a`), 강사명(`.detail_info` 두 번째 span), 강좌구분(`.flag_ro_col2`), 난이도(`.flag_ro_col3`)를 추출합니다.
5. 특정 페이지에서 강좌가 하나도 파싱되지 않거나 예외(타임아웃 등)가 발생하면 해당 과목의 마지막 페이지로 판단하고 다음 과목으로 넘어갑니다.
6. 모든 과목 크롤링이 끝나면 결과를 CSV 파일 하나로 저장하고 브라우저를 종료합니다.

## 설치

### 요구 사항

- Python 3.8 이상 권장
- 로컬에 설치된 **Google Chrome** 브라우저 (ChromeDriver는 `webdriver-manager`가 자동으로 설치합니다)

### 1. 저장소 클론

```bash
git clone https://github.com/Team-Andante/EBSi_Class_Crawler.git
cd EBSi_Class_Crawler
```

### 2. 의존 패키지 설치

```bash
pip install beautifulsoup4 selenium webdriver-manager
```

## 사용법

```bash
python class_crawler.py
```

실행하면 아래 메시지가 표시됩니다. 크롤링할 학년 번호(1, 2, 3 중 하나)를 입력하고 Enter를 누르세요.

```
크롤링할 학년을 선택해주세요. (1: 고1, 2: 고2, 3: 고3)
```

번호를 입력하면 headless Chrome이 실행되며 선택한 학년의 전체 과목을 순서대로 크롤링합니다. 진행 상황은 콘솔에 다음과 같은 형식으로 출력됩니다.

```
▶ [high2] 국어 시작 (지정 페이지: 6)
  1/6 페이지 완료
  2/6 페이지 완료
  ...
▶ [high2] 영어 시작 (지정 페이지: 6)
  ...

✅ 완료! 총 <N>개 데이터가 ebs_high2_data.csv에 저장되었습니다.
```

## 출력 결과

크롤링이 끝나면 스크립트를 실행한 디렉터리에 CSV 파일이 생성됩니다. 각 행은 강좌 하나를 나타내며 컬럼 구성은 다음과 같습니다.

| 컬럼 | 설명 |
| --- | --- |
| 과목 | 강좌가 속한 과목명 (국어, 영어, 수학 등) |
| 강좌명 | 강좌 제목 |
| 강사 | 담당 강사명 |
| 강좌구분 | 사이트에 표시되는 강좌 유형 플래그 |
| 난이도 | 사이트에 표시되는 난이도 플래그 |
| 링크 | 강좌 상세 페이지 URL |

## 주의사항 및 문제 해결

- 이 크롤러는 EBSi 웹페이지의 HTML 구조(CSS 클래스명 등)에 의존합니다. 사이트가 개편되면 셀렉터를 수정해야 정상 동작합니다.
- 결과 파일명이 선택한 학년과 관계없이 `ebs_high2_data.csv`로 고정되어 있습니다. 여러 학년을 연달아 크롤링하면 이전 결과가 덮어써지므로, 학년별로 결과를 보관하려면 실행 후 파일명을 직접 변경해 주세요.
- `init_set()`에 별도의 예외 처리가 없어 1~3 이외의 값을 입력하면 오류가 발생합니다. 안내 문구에 맞게 1, 2, 3 중 하나만 입력해 주세요.
- 페이지 로딩 대기(최대 10초)와 페이지 간 딜레이(0.7초)가 코드에 고정되어 있습니다. 네트워크 상황이 느리면 일부 페이지가 누락될 수 있으니, 필요하면 `crawl_subject()`의 대기 시간을 늘려 사용하세요.
- 과도하고 반복적인 요청은 대상 서버에 부담을 줄 수 있습니다. 개인 학습 · 정보 수집 목적으로 사용하고, EBSi의 이용약관을 확인한 후 사용해 주세요.
